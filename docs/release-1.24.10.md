# Release 1.24.10 — Availability and packet-loss evidence

Includes the availability timeline, historical-range and confirmed-outage clarity improvements prepared in 1.24.9. The packet-loss overview now converts stored fractions to percentages, so complete loss displays 100% rather than 1%. Rollup averages are weighted by recorded checks, and missing measurements remain unknown. The summary, sparkline, health assessment and detail dialog use the same percentage units.

No monitoring thresholds, incident detection rules, telemetry or database schema change. The update remains appliance-only and preserves installed Windows agent packages. Validation covers complete and partial loss, weighted rollups, missing values, strict dashboard compilation, route checks, required CI and signed update acceptance on the development appliance before public promotion.
