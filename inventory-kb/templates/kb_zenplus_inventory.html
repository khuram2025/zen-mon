ZenPlus Inventory

Inventory

Every operating system, firmware release, software title and hardware model across your servers and network devices, in one place. Nearly every count is a link to the machines behind it. This is the overview: what Inventory answers, what each screen is for, and where to start.

Applies to ZenPlus 1.24.0+ Updated 2026-10-09 Audience Operators and administrators Reading time ~6 min

01 What Inventory answers #

ZenPlus already collected most of what an asset inventory needs: the Windows agent reports the operating system and the installed programs of a server, and the SNMP poller reads the vendor, model, serial number and firmware of a network device. Inventory puts those facts side by side, normalises the names so that “Windows Server 2019 Standard” and “Microsoft Windows Server 2019 Datacenter” land in the same release, and keeps a history of what changed.

It exists to answer the questions that are otherwise a spreadsheet exercise:

  • How many of X do we have? How many servers run Windows Server 2019, how many FortiGates, how many hosts have Chrome.
  • Which machines run version Y? Every count opens the list of machines behind it, so “which FortiGates run 7.2.x” is two clicks from the Overview.
  • What changed? Installs, removals, upgrades, operating-system changes, firmware changes and hardware swaps are recorded as they are reported, with the date.
  • What is missing? Devices without a model or serial number, servers that stopped reporting, and servers with no endpoint protection are shown as a worklist, not hidden. Where the data cannot answer (for example a server whose software list has not arrived), the screen says unknown rather than guessing.

02 The screens, and what each one answers #

Inventory lives in the Inventory & Compliance group of the sidebar (shown as Inventory when the sidebar is collapsed). Its screens are also a tab strip under the Inventory heading, so you can move between them without the sidebar. A line under the tabs says how fresh the data is and how many assets are not reporting; each count in it is a link.

Overview
The whole estate at a glance: six key figures, the operating-system and firmware mix, the top software and the products with the most versions (on a very large estate, among the most installed products; a note under the panel says how many were ranked), hardware, the latest changes and the inventory health worklist.
Assets
Servers and network devices in one filterable list. Click a row for the asset flyout: identity with the source and age of each value, software or modules, and recent changes.
Operating Systems
A family, release and version tree for server operating systems and network firmware, with the share of machines on the newest version seen.
Software
One row per installed product, with host counts and the distribution of versions. Open a product for its versions, the servers it is installed on, its timeline and the raw names behind it.
Hardware
Network vendors and models with serial-number coverage, a models-by-firmware matrix, chassis and module groups, and CPU, memory and disk distributions for servers.
Changes
What was installed, removed, upgraded or swapped, newest first, grouped by day, over 24 hours, 7, 30 or 90 days.
Inventory Settings
Freshness targets, how long change history is kept, the daily snapshot time and the software categories hidden by default. Everyone who can open Inventory can read it; changing it needs the inventory.manage permission.

03 Three rules the screens follow #

Counts of machines are links, and the list matches the number

Click “23 servers on Windows Server 2019” and the Assets list that opens has a total of 23. The filters are in the address bar, so you can bookmark or send the exact view. Figures that are not a count of machines (for example the number of components in a chassis, or the Behind latest figure of a product) are plain text, not links.

Unknown is a value

A machine whose operating system, vendor or model could not be identified is shown as Unknown. It is counted, it has its own row or slice, and you can click it. Nothing is quietly dropped or counted as healthy.

Every value has an age

Freshness badges say whether a machine reported recently, and the asset flyout shows the source and age of each identity value. See Reading the health panel and freshness badges.

You only see what your role covers

If your role or your user account is limited to tags, every number on every Inventory screen covers the assets with those tags only, and a badge under the tabs says so. See Permissions, tag scope and team roles.

04 What is not in this release #

This release delivers the inventory itself. These are not part of it, so you do not look for them:

Not in this releaseWhat you see
End-of-life and end-of-support datesBuild currency compares versions with the newest version seen on your own assets, not with the vendor’s latest release
Compliance policies and vulnerability matchingNothing; the sidebar group has no Compliance rows
Editing software catalog rules, owners, criticality and saved viewsRead-only: the Evidence tab shows the raw names behind a product, and unmatched titles are counted
Server manufacturer, model, serial number, BIOS and physical-or-virtualThe Windows agent in this release does not report them. The Hardware page says so, and servers show CPU, memory and disks
Software on Linux servers and on servers without the agentNo software list. See what is not collected
History from before the module was installedHistory starts when the release that introduced Inventory was installed (the Changes page prints that date) and cannot be reconstructed. See when history starts

05 Where to start #

Make sure the sources are reporting

Inventory needs no setup of its own, but it is only as complete as the agent and SNMP coverage behind it. See Getting started.

Read the health panel

The Inventory health panel at the bottom of the Overview is the quickest list of gaps to close: devices without a model or serial, servers that never reported, servers with no endpoint protection. See health and freshness.

Ask your first question

“Which servers run Windows Server 2019?” Click the operating-system row on the Overview. “Which hosts have an old Chrome?” Open the product on the Software page and click a version.

Give the right people access

Custom roles do not receive Inventory access automatically. See Permissions.
