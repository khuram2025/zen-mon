Check the file before you import it. Download the checksum, its signature and the public verification key, then compare the hash:

# Windows PowerShell Get-FileHash .\{{ verify_example }} -Algorithm SHA256 # Linux and macOS sha256sum {{ verify_example }}

To confirm the checksum itself was published by Zentryc:

openssl pkeyutl -verify -pubin -inkey zentryc-release.pub -rawin \ -in {{ verify_example }}.sha256 -sigfile {{ verify_example }}.sha256.sig
