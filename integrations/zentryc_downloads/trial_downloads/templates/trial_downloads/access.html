Step 3

Import and complete first setup

  1. Import the package with the steps for VMware or Hyper-V. Keep the CPU, memory, both disks, UEFI and Secure Boot as delivered.
  2. Connect the management network adapter to a trusted network with DHCP and power the VM on. Initialisation takes several minutes.
  3. Open the VM console and sign in with the first-use login given in the installation guide. You are asked to replace the console password and to choose a separate web administrator password.
  4. When the console shows Setup complete, open the HTTPS address it displays and sign in as admin with your new web password.
  5. Add your first devices. The trial started at first boot and needs no key.
